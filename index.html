Pipeline Defender is a small arcade game about the job every CI/CD pipeline does: stop failing builds before they reach production. Its repo ships itself through the same kind of pipeline.

Move the QA gate with ← → or A D, or jump to a lane with 1 to 4. Block the red builds, let the green ones ship, and avoid an incident.

  • Tested on every push. pytest runs headless, including a smoke test that plays 6,000 frames with a random player.
  • Built to WebAssembly. pygbag compiles the Python game so it runs in any browser.
  • Deployed automatically. GitHub Actions publishes to GitHub Pages with short-lived OIDC credentials, so the repo stores no deploy tokens.
